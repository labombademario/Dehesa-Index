IMPORTANT WARNING ON INDICATOR, DATA AND FILE VERSIONS
------------------------------------------------------

INDICATOR VERSIONS CHANGELOG
----------------------------
Please note that:
- From February 2026: the first version of the Combined Drought Indicator (CDI) considered in this folder is 4.1.0
- On 2026-07-24: the CDI has been upgraded from version 4.1.0 to version 4.1.1 to state the transition from Suomi NPP to NOAA-21 in acquiring VIIRS source data for computing the fAPAR Anomaly component.

In this folder you can find:
- data of version 4.1.0 from 2012-01-01 (first ten-day period of January 2012) to 2026-06-21 (third ten-day period of June 2026)
- data of version 4.1.1 from 2026-07-01 (first ten-day period of July 2026) onwards


DATA VALIDITY AND FILE VERSIONS
-------------------------------

Please note that files ending with pNN, where NN is a 2-digit number, must be considered provisional, since the data they contain are not the final ones but a provisional solution to face delays or other issues.
Final files containing correct data are marked with a zMM suffix, where MM is a number following the last NN number found in pNN files.
For example: 
- cdinx_m_edo_20260121_t_410_p02.tif: provisional file
- cdinx_m_edo_20260121_t_410_z03.tif: final file
